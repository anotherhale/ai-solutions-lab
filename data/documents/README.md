# Documents

Synthetic laboratory files. Treat every file placed here as untrusted input, even though the content is fictional.

`procedures/` is a small procedure corpus for retrieval. `catalog.json` is labeled synthetic and names the pages. Those pages are not loaded by the fixture seed and do not replace `data/fixtures/valid/`.

Document version rows still point at paths such as `synthetic/documents/doc_0001/v1.bin`. Those bytes are not in this repository.
